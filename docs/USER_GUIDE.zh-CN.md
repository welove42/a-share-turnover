# 牛来盯盘：使用手册

本手册对应 **1.23.13**：在 VS Code 中查看行情、图表和财经提醒，也可通过自己配置的 API 进行 AI 分析。最新变化和历史版本见 [更新记录](../CHANGELOG.md)，面向扩展市场的介绍见 [展示文案](../README.marketplace.md)。

## AI 分析：配置一次，按需使用

1. 点自选栏齿轮打开插件设置，选择 **AI 分析**。
2. 填写服务商的 **API 地址** 和 **API Key**。地址例如 `https://api.deepseek.com`，也支持 `/v1` 或完整 `/chat/completions` 地址。Key 使用密码框，可显示本次输入；已保存的 Key 留空保留，输入新值替换。
3. 点 **获取列表**，在模型输入框内搜索、选择，再点 **保存配置**。服务商不支持列表时可直接输入模型 ID（例如 `deepseek-chat`）。获取列表使用当前填写的地址和 Key，不会自动保存或更换模型。
4. 点模型旁的 **测试连接**，会先保存本页配置，再显示进度、耗时及成功 / 失败原因；测试中可取消。列表中的模型不一定都支持聊天，可通过测试确认。测试会产生少量 API 用量。
5. 点击 A 股自选行右侧的 **AI 分析图标**（折线图＋星芒，在底部显示和删除按钮前）；图表右上角也有 AI 按钮。分析大盘则点击底部成交额，在菜单选择 **AI 分析大盘**。

点击分析对象下拉，在右侧面板内按自选名称或代码筛选，支持方向键、Enter 选择、Esc 或点击空白收起。展开和搜索不调用 AI；选择新对象开始分析，有历史时恢复原对话。

新分析默认分为四部分：**一句话结论、各周期怎么看、接下来盯什么、最需要小心**。月线看长期背景、周线看阶段趋势、日线看近期变化、分时看当天持续性；周期冲突会解释，不凭一天上涨认定趋势反转。旧对话不会自动补数据，点击 **重新分析** 后使用多周期分析。

结果显示在右侧，可以继续写代码，也可以输入问题追问。追问沿用本次快照；**重新分析** 才获取新行情。**停止** 中止当前请求，**清空** 删除当前对话。对话、行情快照和追问草稿自动保存在本机，重载或重启后恢复；再次打开同一个股时优先恢复原对话，**重新分析** 新建一段并刷新行情。点击右侧分析面板顶部的 **历史**，在面板内切换旧对话，最多保留最近20段（总大小约3百万字符），也可清空全部历史。恢复历史不会自动调用 API。没有后台自动分析，不需要每天配置。

等待时会显示连接、等待回复、模型思考或接收正文，以及已等待秒数。请求失败或停止后直接显示原因，不再保留“正在思考”。连续90秒无新内容或单次请求超过180秒会停止，并区分“尚未收到正文”和“回复中途停止”。已收到部分正文时，输入“继续”可补全，也可直接追问；会带入原行情和标记为未完成的回复。生成过程中可先写问题，结束或点击停止后再发送；不会自动重复调用。OpenAI 使用新的输出长度参数，为推理模型预留推理额度（计入服务商用量），其他兼容接口沿用原参数。

追问框会随文字自动增高，发送按钮在右下方，也可按 **Ctrl / ⌘ + Enter** 发送。点击 **诊断** 查看最近一次请求的首字耗时、接收数量、正常结束或超时原因；只保留诊断数值，不记录 Key、提示词、正文或模型思考内容。

支持 A 股、场内 ETF、沪深指数。每次分析自动带入：

- **个股**：最多60根月K、120根周K、240根日K及五日分时。程序计算均线方向、高低区间、MACD / RSI和量能，发送摘要及每周期最近3根K线，避免堆积原始数据。
- **大盘**：上证、深证成指、创业板、沪深300，以及沪深成交额、同刻放缩量、涨跌家数和市场温度；分析大盘时同时参考四个指数的月、周、日线。
- **所属板块**：按股票代码查询行业及相关标签，带入涨跌幅、成交额与涨跌家数；补充行业与基准近5 / 20 / 60个交易日的表现，起止日一致才比较相对强弱。
- **全球环境**：纳指、标普、道指、恒指、日经、韩国 KOSPI、德国 DAX、英国富时、法国 CAC 和美元指数，补充这10项的历史涨跌；报价可包含用户关注的其他指数，最多24项。
- **商品与快讯**：黄金、布油、伦敦铜、伦敦银参考行情，以及最近48小时中优先与标的、板块及宏观相关的最多12条快讯。

面板会显示本次各类数据的覆盖数量。AI 综合大盘、板块和外围影响，给出有条件的建议与观察点，并说明判断何时失效。每项数据保留来源和时间，不同国家可能使用上一交易日收盘数据。接口有独立超时，失败时保留有效缓存并标注缺失；同一分钟内复用背景快照，追问不重复请求。

当天日K有同日收盘报价才视为已完成，当前周/月K保守标记为“形成中”。确认指标及量比使用已完成周期，形成中的价格和指标另列；盘中量仅与历史同一分钟比较。全球历史只使用源日期已过36小时的数据，可能比最新报价晚，以各项截止日期为准。历史高低点仅作为观察区间，不能视为保证有效的支撑或压力。

所属板块最多80项，截断会标注；地域和风格标签不等同独立行业。ETF带入可取得的IOPV与折溢价，未确认的跟踪指数和成分不猜测。新闻是公开快讯选摘，未接入财报或ETF成分。港美股、场外基金暂不支持 AI 分析。

Key 保存在 VS Code 安全存储，不写入 `settings.json`。接口更换后需为新地址重新保存 Key。请求只发送公开行情、快讯和本次对话，不读取代码、文件或个人持仓；对话保存在本机的插件存储中，不加入 VS Code 设置同步；历史只有在你主动追问时才发送给当前配置的 API。老板键隐藏分析内容并中止请求，保留本地历史，恢复后不自动调用。中止前服务商已处理的部分仍可能计费。

需要 **VS Code 1.109+**。API 使用 HTTPS，本机 `localhost` / `127.0.0.1` / `::1` 可用 HTTP；本机免鉴权的兼容服务可填写非空占位 Key。接口无效、权限不足、限流或超时会在面板显示原因。AI 内容可能有误，只作为行情解读参考。

## 插件设置与个股涨跌提醒

点击自选股栏目右上角的齿轮，或点击底部成交额后选择“插件设置”。设置页按功能分类，支持搜索、自动保存和单项恢复默认，不需要编辑配置文件。

配色：打开 **自选与图表 → 自选配色**，选择 **红涨绿跌（默认） / 跟随主题 / 自定义**。跟随主题时使用常规文字颜色，靠箭头和正负号区分涨跌；自定义时点击色块或输入 HEX 颜色，也可把上涨、下跌设为同一颜色。修改后立即应用到 A 股、港股、美股列表的涨跌箭头和底部股票行情，无需重新加载。平盘、暂无报价不染色；底部暂停或过期行情仍使用常规颜色。

自选、指数、基金和商品按名称＋代码展示。在对应分组点击“添加”，点击条目右侧“×”移除；长名单可按名称或代码筛选。基金旁的“持仓”按钮可直接编辑该基金的份额和成本。

自选分组：在侧栏 **A Stock、港股、美股** 行点击“新建分组”文件夹图标；分组行的 **＋** 可按名称或代码添加该市场个股。拖动个股到另一分组即可移动，右键个股也可选择“移动到分组”。拖动分组调整顺序；右键分组可重命名或删除。

各市场独立管理，每只个股只属于本市场的一个分组，未归类个股显示在“未分组”；删除分组只把个股移回未分组，不删除自选。设置页也支持新建、重命名、删除、上下排序及下拉选择分组。分组和顺序重启后保留；涨跌幅排序在各组内生效，拖动个股会切回手动排序。不能跨市场移动个股或分组。

大盘成交额提醒：默认放量或缩量**超过 20%** 时右下角弹窗，状态栏成交额一栏放量红色、缩量绿色。每天两个方向各提醒一次，重启不重复；回到阈值内恢复常规颜色设置。弹窗和变色沿用状态栏的比较口径，默认比较上一交易日同刻；如改为昨日全天，盘中累计额通常偏低。

在设置页“涨跌提醒与风险”中可修改阈值，独立关闭弹窗或变色。老板键开启、暂停、禁用成交额或数据过期时不弹窗；午休和收盘后只保留有效行情的颜色提示。

在“涨跌提醒与风险”中选择提醒方式：**一直提醒 / 一直不提醒 / 老板键激活时不提醒（默认）**。自选 A 股、港股、美股的最新涨幅超过 7% 或跌幅超过 7% 时，在右下角显示提醒；等于 7% 不触发。当天同一股票上涨、下跌各最多提醒一次，重启保留去重记录。

提醒只使用交易时段的有效近期报价；关闭自选行情或暂停刷新时停止监测。选择“一直提醒”后，老板键开启期间仍每 10 秒后台监测自选并允许弹窗。VS Code 未运行或处于勿扰模式时不能保证弹出通知。

## 老板键：一键隐藏行情

首次安装默认显示行情。需要隐藏时，在 VS Code 中按 **Ctrl+Shift+;**，隐藏插件的状态栏内容、侧栏行情和输出面板；活动栏入口使用中性的工作台图标，点击后显示调试引导（按钮仅作展示，点击不会执行操作），并关闭插件打开的图表和新闻标签页；再按一次恢复。隐藏期间暂停刷新和新提醒，不会补发隐藏期间已错过的提醒。恢复后保留原来的自选数据和各栏目的暂停设置，关闭的标签不会自动重新打开。重启 VS Code 后仍保持隐藏状态。

快捷键冲突时，按 **Ctrl+K**、再按 **Ctrl+S** 打开键盘快捷方式，搜索“切换隐藏模式（老板键）”，设置自己喜欢的组合键。也可以在命令面板搜索该命令切换。

老板键仅影响当前 VS Code 窗口里的本插件，已经出现的系统通知或在浏览器打开的网页不会自动关闭。

1.2.1 将命令、视图和活动栏 ID 改为发布者独有的命名空间，修复旧版与新版同时安装时“添加”仍调用旧代码输入框的问题。新版入口标题为 **搜索并添加自选股**。如果仍看到“添加自选股（可批量输入）”，请在扩展管理中禁用 / 卸载 `local-market-tools.a-share-turnover` 并重新加载窗口。

发布标识：`welove42.a-share-turnover`。此前本地测试包使用 `local-market-tools.a-share-turnover`，安装本版后请禁用或卸载旧标识，避免重复显示；`aShareTurnover.*` 用户设置可继续使用。

## 板块涨跌榜

点击底部 **领涨 / 领跌**，选择 **涨幅前十 / 跌幅前十**；同一菜单也可切换行业、概念板块或立即刷新。选择自动保存，重启后保留。状态栏显示对应榜单第一名，悬停查看前十和行情时间；设置页“状态栏与市场 → 涨跌榜”也可切换。

涨幅榜按涨跌幅从高到低，跌幅榜从低到高；某方向不足十个时包含其余板块并说明。涨跌榜分别缓存，不将涨幅前十倒序当作跌幅前十。交易期间行业每10秒、概念每60秒刷新，午休及休市不持续轮询。东方财富失败时尝试备用节点，再从新浪完整榜单中取对应前十；新浪最多每60秒获取一次，分类口径可能不同且不提供原始行情时间，会明确标注。全部来源失败时保留对应榜单缓存并在悬停说明；非交易时段首次失败后最多每分钟重试至累计5次。

设置 `aShareTurnover.sectors.category` 为 `industry`（行业，默认）或 `concept`（概念）；`aShareTurnover.sectors.enabled` 可关闭。排行和行情时间以实际来源为准，可能延迟。

## 自选股侧栏

左侧活动栏点击插件的 **工作台** 图标，打开「自选股」：

1. 点击视图标题上的 **＋**，输入中文名、拼音或编号，例如 `贵州茅台`、`平安`、`gzmt`、`600519`。该入口可同时搜索 A 股、港股和美股；候选标注市场、名称和代码，选中后加入对应分组。输入约300毫秒后搜索，快速改词会取消旧搜索。
2. 完整代码可直接添加，支持批量输入 `600519, 000001, 300750, 510300, sz159915`，用空格、中文或英文逗号分隔。网络搜索失败时仍可通过完整代码添加。
3. 每行依次显示 **涨跌幅、现价、名称**，上涨红色箭头、下跌绿色箭头。ETF 保留三位价格小数。
4. 悬停查看代码、昨收、涨跌额、最高 / 最低价和北京时间行情时间。
5. **点击个股行**查看详细图表。右键或行末按钮删除自选、选择在底部显示；顶部提供刷新、排序和暂停 / 恢复。
6. **拖拽自选股调整顺序**：拖到目标股票行，向上拖放到目标前面、向下拖放到目标后面；拖到 `A Stock` 分组标题或列表空白处可移至末尾。顺序会保存，刷新或重启后保留。若此前按涨跌幅排序，拖拽后会以当前显示顺序为基础切回手动排序；可通过顶部排序按钮重新选择按涨跌幅排列。

支持沪深股票、ETF，以及行情源支持的北交所股票。六位代码自动识别市场；也支持 `sh600519`、`sz000001`、`bj920002`、`600519.SH` 等写法。**`000001` 默认指平安银行；上证指数必须写 `sh000001`。** 自选最多 100 个，重复代码自动去重，不预置任何个股。

也可以通过代码管理 A 股自选：按 `Ctrl+Shift+P`，搜索并选择 **Preferences: Open User Settings (JSON)**，打开用户设置文件。下面是一个示例：

```json
{
  "aShareTurnover.stocks.symbols": [
    "sh600519",
    "sz000001",
    "sz300750",
    "sh510300",
    "sz159915"
  ],
  "aShareTurnover.stocks.statusBarSymbol": "sh000001",
  "aShareTurnover.stocks.sortBy": "manual"
}
```

股票代码必须加引号，避免前导零被丢弃。`sortBy` 可选 `manual`、`percentDesc`、`percentAsc`。添加、删除和选择底部代码都会保存到用户设置，重启后保留。若旧版本清单未注册设置、设置文件不可写等原因导致保存失败，会改用插件持久存储，操作仍然生效；下次成功写入设置后恢复正常。设置页面手动编辑名单时应填写股票代码，名称搜索通过添加入口进行。

示例中 `stocks.symbols` 是 A 股自选列表；`sh600519` 是贵州茅台，`sz000001` 是平安银行。`stocks.statusBarSymbol` 决定底部显示的代码，`sh000001` 是上证指数。`stocks.sortBy` 控制排序，`manual` 表示手动排序。上面的代码是完整示例：如果文件中已有其他设置，请只把需要的设置项合并到原有 `{ }` 内，设置项之间用逗号分隔。

### 港股与美股

自选股下有与 `A Stock` 同级的 **港股**、**美股**折叠分组。点击对应分组行尾的 **＋**，按名称或代码添加，例如 `腾讯` / `00700`、`苹果` / `AAPL`；顶部 **＋** 也能统一搜索。各市场最多100只，支持删除、组内拖拽排序，并使用相同的涨幅排序设置。

港股按当地工作日常规时段每10秒获取腾讯行情，中午休市。点击 **美股标题行右侧的时钟切换图标**，选择 **自动 / 盘前 / 盘中 / 盘后**，当前模式在标题旁显示。默认“自动”随美东交易阶段切换；选择会保存在本机，重启后保留，全部美股及自定义分组统一使用。

手动选“盘中”时，即使当前处于盘前，也可查看最近一次常规交易行情，非当日报价会标出日期。手动选择的盘前/盘后尚未采集、过期或没有有效数据时，价格和涨跌幅显示“—”，旁边注明“暂无”；有效历史报价保留原日期，不会拿其他时段的数据代替。涨跌排序同步使用当前显示的数据，切换不额外请求，也不改变提醒规则。悬停仍能同时查看常规及已获取的盘前、盘后报价、行情时间和基准价。

美股常规报价来自腾讯，盘前盘后来自新浪。盘前涨跌对比上一常规交易日的收盘基准，盘后对比当日常规收盘基准；基准以盘前盘后数据源为准，可能含收盘修正，与常规行情显示的价格有差异。两种百分比不能混为一谈；原有7%提醒仍使用常规行情。

工作日按美东时间刷新，自动适配夏令时：盘前 **04:00–09:30**，常规 **09:30–16:00**，盘后 **16:00–20:00**；盘前盘后每10秒请求，20:00后短暂补取最终报价，常规时段每分钟补取一次扩展时段数据。可识别数据源返回的提前收盘后的盘后报价。无需额外配置，暂停和老板键会中止请求。

数据源通常只返回最近一次盘前或盘后报价，插件将两类分别缓存：首次没有采集到的时段显示“暂无有效报价”，不会补造为0%。报价时间较早、网络失败和缓存均会标明；昨天盘前不当作今天盘前，夜间或周末可保留最近盘后报价并标日期。公开行情可能延迟。

## 基金与个人持仓收益

插件侧栏下新增独立的 **基金** 折叠栏目，默认空列表，最多关注50只基金。

1. 点击栏目右上角 **＋**，输入中文名称、拼音或六位基金代码（保留前导零），选择候选后添加。完整代码也可批量输入，例如 `110020, 000198`；这里的代码仅为操作示例。
2. 默认自动显示可用的 **盘中估算涨跌、估算净值、基金名称和时间**，行首标“估算”；当天正式净值公布后自动改为“净值”。估值缺失或过期时也显示已公布净值，日涨跌缺失则显示“—”。列表可见时每60秒检查，折叠、暂停或老板键隐藏后停止持续请求。
3. 点击行末 **铅笔**，依次填写 **当前已确认持仓份额**、**剩余持仓总成本**。两步都完成才保存，取消不会修改之前的持仓。金额应与基金净值同币种，总成本可包含费用，不是单位成本。
4. 设置后列表显示持仓收益和收益率，使用估值时标“估算持仓”。悬停同时查看 **今日预估收益、预估持仓收益、按正式净值计算的持仓收益**，以及来源和日期。`持仓收益 = 份额 × 净值 − 总成本`；`今日预估收益 = 份额 ×（估算净值 − 基准净值）`。
5. 申购、赎回、份额折算或分红再投资后需手动更新份额和剩余成本；已收现金分红可自行从成本扣除。这里计算当前剩余持仓，不自动处理交易流水、汇率换算或已赎回收益。估算不等于基金实际收益，ETF 的估算净值也不是场内成交价。
6. 货币基金单独显示 **万份/百份收益、七日年化及日期**，不把收益字段当净值。货币基金累计持仓收益依赖交易流水，本版不按单位净值估算其个人持仓盈亏。

持仓份额、成本只保存于本机扩展存储，不写入用户/项目设置，也不会发送给行情接口。关注代码保存在 `aShareTurnover.funds.symbols`；设置 `aShareTurnover.funds.enabled` 可单独关闭栏目。右键 **移出列表** 保留本机持仓，重新添加会恢复；**清除本机持仓** 则保留基金关注，仅清除份额和成本。

在 **插件设置 → 指数、基金与商品 → 显示基金盘中估算** 可关闭估算，只看正式净值。部分主动基金、货币基金等没有盘中估值，不会显示为零或推测收益。

基金数据由[天天基金 / 东方财富](https://fund.eastmoney.com/)提供，估值使用 `FundValuationLast` 批量接口，主域失败尝试备用域名。只使用今日、基准与正式净值一致的估值；超过15个交易分钟未更新时回退到正式净值，午休与收盘不累计交易分钟。接口失败或重启后，仍有效的估值可保留并标记“缓存”；过期估值只在悬停中供回看。QDII等基金可能晚于A股日期更新，始终显示真实公布日期。点击基金行在浏览器查看完整详情。

## 市场温度

底部新增紧凑的 **温度 77 偏热** 入口（示例），用于观察沪深A股整体情绪。它是本插件的自定义0–100分指标，名称不代表交易所发布的官方指数。与底部选择的个股无关，也不依赖自选股模块。

| 得分 | 状态 |
| --- | --- |
| 0–19 | 冰点 |
| 20–39 | 偏冷 |
| 40–59 | 中性 |
| 60–79 | 偏热 |
| 80–100 | 过热 |

计算使用上证A股（000002）与深证A指（399107）的行情，不含北交所和B股。涨跌家数沿用腾讯接口的统计口径，可能与其他数据源不同。三个分项分别限制在0–100，按以下权重求和并四舍五入后分级：

- **涨跌家数60%**：`100 ×（上涨家数 + 平盘家数÷2）÷总家数`。沪深家数相加，平盘按半份计入。
- **指数走势25%**：`50 + 沪深A股指数涨跌幅的算术均值÷3 × 50`。平均涨幅+3%对应100分，-3%对应0分；这不是按市值合成的新指数。
- **成交活跃度15%**：`50 + 较昨日同刻成交额变化百分数`。例如放量20%对应70分；始终使用昨日同刻，不受成交额显示的“较昨全天”设置影响。放量也可能发生在下跌中，需要结合涨跌家数与现有风险提示查看。

状态栏悬停可看上涨/下跌/平盘家数、两市指数涨跌幅、同刻成交额变化和每个分项得分。**点击底部温度**或运行命令 **牛来盯盘：查看市场温度走势图**，打开当日曲线；重复点击复用同一个标签页。右上角提供刷新行情和查看计算明细按钮；命令 **牛来盯盘：查看市场温度计算明细** 也可在底部“输出 → A股市场温度”查看完整依据。

- 曲线横轴为北京时间的本机采集时刻，纵轴为0–100分，背景标出五档温度，并显示当日最高、最低和最近记录。
- 鼠标悬停显示对应日期、时分秒、分数与冷热等级；左右方向键逐点查看，移出或按Esc恢复最近记录。自动刷新保留已选中的采集时段。
- 每分钟最多记录一次，相邻点连成折线，缺采超过3分钟用虚线连接，午休留空；只允许悬停实际记录，不补造中间数据。旧版10秒记录自动整理，本机保存、重启续接当天、次日清空。
- 横轴固定09:30–15:00。收盘确认保留一个端点，悬停显示实际采集时间；午休和盘后手动刷新不追加走势记录。无需一直打开图表，配色跟随 VS Code 主题。

复用成交额模块已有的两市行情，每10秒刷新，**没有新增轮询接口**。开盘前5个交易分钟显示“开盘观察”，09:35起分级；午休和收盘后保留同日有效快照并注明状态。两市不同步、报价过期、基准缺失、家数覆盖不足、缓存/旧日行情或请求失败时显示“待更新”，不会用缺失值补出中性或极端温度。暂停成交额时温度也暂停，盘前及休市显示相应状态。

设置 `aShareTurnover.temperature.enabled: false` 可隐藏温度；`aShareTurnover.temperature.colorize: false` 取消温度配色。默认热为红色、冷为蓝色、中性为主题默认色。关闭成交额模块也会隐藏温度。温度描述当前市场参与度与活跃度，不是未来涨跌预测。

数据字段依据[腾讯指数页面](https://gu.qq.com/sh000002/zs)及[腾讯官方前端的涨/平/跌家数映射](https://st.gtimg.com/quotes/hs-fund/bundle.13362df9.js)核对。开发者可运行 `npm run smoke:temperature` 检查实时字段与评分结果。

## 点击个股查看详细图表

点击 插件侧栏中任一个股 / ETF 行，在编辑区打开行情详情标签。**所有股票共用一个详情标签**：点击其他股票时更新标题和内容，并保留当前图表类型；重复点击同一股票只聚焦，不重载网页。命令面板的 `A股自选股：查看详细行情图表` 默认打开底部当前显示的代码，因此也能查看上证指数。

**分钟K线**：支持1、5、15、30、60分钟，使用腾讯行情的真实开高低收和成交量。点击图表周期旁的“＋ / −”或在图表上按住 Ctrl 滚动，可缩放K线；最多显示已获取的240根。时间为周期结束时间，最后一根可能尚未完成；源数据不复权，部分品种可能无数据。

**风险提示**：默认在上证指数跌幅至少1.5%且沪深成交额较昨日同刻放量或缩量至少30%时，在成交量状态栏显示“放量下跌”或“缩量下跌”。悬停可查看数值与阈值；行情过期、暂停、失败、不同日期或时间相差超过2分钟时不提示。可用 `aShareTurnover.risk.enabled`、`risk.volumePercent` 和 `risk.dropPercent` 设置。此提示使用上证指数，不随底部选中个股改变。

**周期直接在图表内切换**（右上角菜单不再重复列出内置周期）：页面提供“分时 / 5日分时 / 1、5、15、30、60分钟 / 日K / 周K / 月K”按钮，当前周期高亮。点击立即切换并保留当前指标，重复点击当前周期不会重载；切换其他股票后仍保留所选周期。

内置行情图表上方的行情明细统一显示**高、低**：分时使用匹配行情日期的当日最高和最低，红绿相对昨收；鼠标移动时仍显示当日最新高低，不代表悬停分钟时已达到的高低。五日分时悬停历史日期时，缺少对应日高低报价则显示“—”。K 线的高低则来自所选周期数据，数据源精度和复权方式可能与实时报价不同。报价缺失时显示“—”，并尝试腾讯备用报价。分时图以水平参考线标出日最高和日最低；五日分时仅在报价对应的最后一个交易日区域显示。由于报价未提供极值发生的准确时间，参考线不代表具体分钟；报价日期与图表日期不一致时不绘制。内置 A 股个股图表顶部显示**最新换手率**及腾讯行情报价时间。图表上方的明细按开收、高低、涨跌、换手和成交量分组，价格相对前收红涨绿跌；明细随鼠标或左右键切换，日、周、月和分钟 K 线显示对应周期的换手率，数据来自东方财富；沪深股票的日、周、月 K 线及 5 日分时支持搜狐财经备用，分钟 K 线使用东方财富备用域名，北交所日周月线仅使用东方财富。5 日分时显示该交易日的全天换手率，最后一个交易日显示数据源最新值。数据旁显示来源和获取时间；请求失败显示原因，可点击图表右上角刷新重试；已有数据会标记为缓存。自动请求间隔至少 60 秒，缺失时显示“—”，不影响图表。1 分钟历史覆盖范围受数据源限制，较早数据可能缺失。指数和基金不显示该字段。

编辑器右上角提供三个图标按钮：**切换图表来源**（折线图图标，仅选择东方财富常规图表 / 筹码盘口；网页模式下提供“返回内置图表”，恢复上次内置周期）、**刷新当前图表**、**在浏览器打开当前图表**。按钮仅在行情详情标签出现；切换菜单会标出当前类型，并提供用途说明。

- **分时图（内置，默认）**：使用腾讯行情直接绘制最近交易日的分钟价格、昨收参考线、涨跌幅及每分钟成交量，午休时间轴合并，不加载东方财富网页。股票和ETF的黄色均价线 = 累计成交额（元）÷累计成交量（手）÷100，包含当日集合竞价成交；它是成交量加权均价，不是价格的简单平均。指数的成分股成交量无法用于计算指数均价，因此指数不画此线。源数据缺失、无成交或成交额异常时显示“—”，不估算。
- **5日分时（内置）**：显示最近最多5个交易日的逐分钟价格、成交量与当日均价，按交易日分段；MACD / KDJ / RSI 每天重新计算。悬停或使用方向键可查看对应日期及指标，历史日期缺少昨收时涨跌幅留空，不用其他日期的数值替代。
- **日K图（内置）**：开高低收蜡烛图、MA5 / MA10 / MA20 / MA30 / MA60 和每日成交量，支持缩放。腾讯返回前复权数据时明确标注“前复权”，指数等无复权数据时标注“不复权”。行情源可能只提供少量历史，按实际可用记录显示。
- **周K / 月K图（内置）**：读取行情源原生周线和月线，显示周期内开高低收、成交量和 MA5 / MA10 / MA20 / MA30 / MA60；支持缩放。当前周/月最后一根尚未收完，会随行情更新，显示实际数据截止日期。
- **常规图表（东方财富）**：按需以 iframe 嵌入 `/basic/full.html` 专用图表页，支持分时、日K及其他周期。沪市使用市场参数1，深市和北交所使用0。网页自行更新行情，插件不会每10秒重载网页。
- **筹码盘口（东方财富）**：沪深A股个股可切换到 `/basic/h5chart-iframe.html`，查看盘口、买卖五档及K线。选择网页内部的 **日K → 筹码分布** 显示筹码图。指数、ETF和北交所暂不开放该入口；从筹码模式切换到这些品种时自动使用内置分时。
- 鼠标移动或聚焦图表后按左右方向键，查看对应分钟 / 日期的开高低收、涨跌额、涨跌幅、振幅、成交量及均线。主图MA5/10/20/30/60和副图图例同步对应位置；成交量区增加VMA5/10。悬浮卡同时列出该时刻MACD（DIF、DEA、柱）、KDJ（K、D、J）、RSI6/12/24，未满窗口显示“—”。成交量图按当前可见数据线性缩放，并提供刻度和参考线；分时柱按相邻分钟价格涨跌着色，首分钟参考昨收，持平或缺少参考价时为中性色。分时另显示均价、分钟与累计成交额、成交量；腾讯科创板成交量由股换算为手，零股保留小数，来源数据明显异常时均价显示“—”。K线接口未提供历史成交额，不使用价格乘成交量估算。图表价格由对应接口精度决定，ETF日K可能比实时报价少一位小数。
- 图表标签可见且交易期间，插件内图表每10秒更新数据；隐藏、关闭或午休后停止轮询。失败保留上次图表并提示；重新显示或手动刷新可获取最新数据。

设置 `aShareTurnover.charts.defaultMode` 可选择新详情标签的默认类型：`intraday`（默认分时）、`intraday5`（5日分时）、`m1` / `m5` / `m15` / `m30` / `m60`（分钟K）、`daily` / `weekly` / `monthly`（日、周、月K）、`eastmoney`（网页常规）或 `chips`（网页筹码）。已有标签切换个股时保留当前类型。

**技术指标**：默认显示 **MACD (12,26,9)** 副图；成交量下方、技术指标副图上方的“副图”按钮可直接选择 **MACD**、**KDJ (9,3,3)**、**RSI (6,12,24)** 或隐藏。副图下方说明随选择更新，列出参数、常见读法及当前周期计算口径；行情未加载时也可查看。右上角不再显示指标按钮，命令面板的“切换技术指标”仍可使用。指标选择保存在本机，切股、切换周期和重启后保留；切换指标只在本地计算，不请求行情接口。鼠标或左右方向键定位时，悬浮卡、主副图图例和图表上方详情同步显示所选时间的指标数值。10秒刷新及切换副图保留已选时间，移出图表、失去焦点或按Esc恢复最新；切换周期或分时跨交易日时清除旧定位。

- **MACD看趋势与动能**：DIF上穿DEA称金叉，下穿称死叉；DIF在零轴上方通常偏强、下方偏弱。柱增长表示DIF与DEA差扩大，缩短表示差收窄，仍需结合价格与成交量。读法参考[TradingView MACD说明](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/)。
- **KDJ看短线位置**：K、D高于80通常视为偏热、低于20偏冷；K上穿D称金叉，反向称死叉。J可超出0–100。强趋势中可能持续钝化，高位或低位均不代表即将反转。
- **RSI看涨跌强弱**：0–100之间，越高表示近期上涨相对更强，越低表示下跌相对更强；6周期更敏感，24周期更平滑。本图20/80虚线标记较极端位置（区别于常见的30/70阈值），不作为确定买卖点。

以上指标均有滞后性，仅作辅助观察；分时每日重置，未收完的K线会随行情变化。

- MACD：DIF = EMA12 − EMA26，DEA = DIF的EMA9，红绿柱 = 2 × (DIF − DEA)；EMA以首个可用价格初始化。公式参考[富途MACD说明](https://support.futunn.com/hant/topic165)与[中国证券投资基金业协会投教资料](https://investor.amac.org.cn/community/tzzhdzthd/ylj/202304/P020230410490474818370.pdf)。
- KDJ：9周期最高/最低价计算RSV，K和D分别按1/3权重平滑，J = 3K − 2D；本插件以50初始化，窗口未满9根不输出，等价区间RSV取50，J可超出0–100。公式参考[富途KDJ说明](https://support.futunn.com/topic149)。
- RSI：6、12、24周期，先用前N个涨跌价差均值初始化，再用Wilder平滑；无涨跌时取50，窗口不足显示“—”。算法参考[TradingView RSI说明](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/)。

**查看更早走势**：日K、周K、月K首次加载近期240根；点击页面内“更早 / 较新”翻页，缩小到已加载边界会自动补载。点击“全部历史”分页加载至数据源最早记录，“最新”返回近期180根。页面显示已加载日期范围和进度；加载失败保留已有走势，再次点击可继续。自动刷新保留历史和浏览位置；若除权导致历史价格口径变化，会提示重新加载。可用起始日期由数据源决定，单个周期最多保留16000根。

指标先用全部已获取记录计算，再按缩放范围截取显示；分钟K仍取近期240根。MA和VMA周期均按当前K线根数计算（周K的MA5为5周、5分钟K的MA5为5根5分钟K）；涨跌额、涨跌幅及振幅按同一复权口径的前一根K线收盘价计算，缺前值或前值不为正时显示“—”。不同历史长度、复权口径和起始值可能造成与其他软件的数值差异。长期前复权历史可能出现负价格，按源数据保留。

分时的指标基于**当日分钟采样价格**并每日重置；KDJ使用采样价格区间，不代表完整1分钟K线高低价。日K、周K、月K则分别以对应周期的真实开高低收计算。

**分时接口501容错**：腾讯主域名的分时请求被WAF拒绝时，会自动切换同格式的公开备用域名`ifzq.gtimg.cn`，图表显示“腾讯行情（分时备用）”。主域名501后冷却5分钟，其他请求故障退避30秒，期间不随10秒刷新反复请求失败接口；取消请求不触发切换。股票、指数及ETF保持原始分钟采样、成交量和累计成交额口径。两源均失败时仍提示真实原因并保留旧图，备用不能保证第三方始终可用。成交额和温度的实时分时请求共用此容错机制。

**验证码与请求优化**：网页验证由东方财富控制，仍可能出现在常规或筹码页面。使用右上角“切换图表来源 → 返回内置图表”即可继续看分时或K线；需要完整筹码功能时，可用“在浏览器打开当前图表”并手动完成验证。浏览器与插件的登录、验证状态彼此独立，完成浏览器验证不保证 iframe 同步通过。插件不会自动识别、完成验证码或复制网站登录凭证。

网页只在宿主确认当前模式后才加载，400毫秒内快速切换类型只加载最终选择；重复选择同一网页不重载，连续网页刷新间隔至少5秒。内置图表按股票和类型复用10秒内的数据，手动刷新间隔至少2秒；切到内置模式会卸载第三方网页。

切换个股会取消旧行情请求，并让旧页面消息失效，避免串股。编辑器右上角的 **在浏览器打开当前图表** 在网页模式下打开当前专用图表，插件内图表模式及个股右键菜单则打开完整行情页。

**自动主题适配**：VS Code 使用暗色主题时，常规图表和筹码盘口采用夜间显示；浅色主题使用原站配色。深色高对比度主题使用黑底效果，浅色高对比度主题保留浅色。第三方网页通过显示层调整配色，红涨绿跌仍可辨认；插件内图表继续使用主题变量。切换主题即时生效，无需刷新，保留当前股票、图表周期及筹码显示状态。

专用页面和单标签交互参考 [leekfund](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/src/webview/stockTrend.ts)。第三方网页的访问策略、数据和登录状态由网站自身管理；内置图表数据通过腾讯行情接口读取。

## 财经新闻（底部输出控制台）

财经新闻**不再占用 插件侧栏**。点击底部 **新闻**，或运行 `A股财经新闻：打开资讯面板`，打开底部 **输出 → 财经新闻7×24资讯**。每条按标题、摘要正文、相关股票（来源有提供时）、北京时间和来源分块展示，类似资讯终端；新内容按时间顺序追加、按ID去重，不反复清空阅读内容。

在 **插件设置 → 财经新闻** 中调整 **高亮新闻标题**，默认开启：标题高亮加粗，正文与时间来源分色，配色跟随主题。关闭后恢复普通文字显示；切换立即生效，不清空已有新闻、不影响未读计数或暂停状态。

- 新闻使用**东方财富公开 7×24 快讯**，无需登录，每 **30秒**刷新，休市时仍运行。
- 首次加载不计未读，之后状态栏累计新增未读数；点击新闻入口清零。后台刷新不抢焦点、不自动弹窗。
- 缓存最近200条，请求失败保留内容并在输出中提示。再次打开缓存会明确标注；已输出的文章不重复追加。
- 在命令面板搜索 `A股财经新闻`，可立即刷新或暂停 / 恢复。暂停与行情独立。

```json
{
  "aShareTurnover.news.highlightTitles": true,
  "aShareTurnover.news.refreshIntervalSeconds": 30
}
```

新闻无需配置 Token。升级后自动使用东方财富，并清理本插件旧版保存的新闻凭证。

## 财经大事提醒

底部日历显示最近的大事及倒计时；悬停查看近期事件、来源、获取时间和覆盖提示，点击打开完整日历。选择其中的事件可打开对应官方页面；选择“刷新日历”可立即重新获取。命令面板也可搜索 **财经大事：查看提醒日历**。

| 类型 | 提醒内容 |
| --- | --- |
| `fed` | 美联储议息决议 |
| `delivery` | A 股股指期货交割日 |
| `cnHoliday` | A 股节假日休市 |
| `hkHoliday` | 港股休市和半日市 |
| `usHoliday` | 美股休市和提前收盘 |
| `nonfarm` | 美国非农数据 |
| `cpi` | 美国 CPI 数据 |

默认在事件前24小时内和30分钟内各提示一次；启动较晚时只提示当前阶段，重启不会重复提示已经发出的同一阶段。通知只在 VS Code 正在运行、扩展已启用时发送。经济数据以北京时间显示，并按美东夏令时转换；休市事件以当地日期为准，界面注明以当地09:30作为提醒时间。

```json
{
  "aShareTurnover.reminders.enabled": true,
  "aShareTurnover.reminders.notifications": true,
  "aShareTurnover.reminders.categories": [
    "fed",
    "delivery",
    "cnHoliday",
    "hkHoliday",
    "usHoliday",
    "nonfarm",
    "cpi"
  ]
}
```

上面的示例开启了全部七类提醒。`enabled` 控制整个大事功能，`notifications` 控制弹窗，`categories` 是要关注的类型；`true` 表示开启，`false` 表示关闭。例如，`categories` 只保留 `"fed"` 和 `"cpi"` 时，就只提醒美联储议息和美国 CPI。

不想编辑代码也可以按 `Ctrl+,` 打开设置，搜索 `aShareTurnover.reminders.categories`，在列表中删除不需要的类型。搜索 `aShareTurnover.reminders.notifications` 并取消勾选，可保留状态栏和日历但关闭弹窗；搜索 `aShareTurnover.reminders.enabled` 并取消勾选，可关闭整个大事功能。

议息、非农、CPI 和美股提前收盘从 [Finance Calendar](https://www.financecalendar.com/) 获取；A 股、港股、美股休市和港股半日市从 [Markets Open](https://marketsopen.today/) 获取。扩展也尝试美联储和美国劳工统计局官方日历。Markets Open 数据按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用，界面保留来源和数据版本。在线日历每日尝试更新；网络失败、数据格式异常或年份未覆盖时，分别使用上次成功缓存或内置官方公告快照，显示来源和获取时间。

内置 A 股、港股休市快照覆盖2026年，美股覆盖2026–2028年；在线源未收录的未来年份不会自动推测。股指期货交割使用中金所规则和已验证的 A 股交易日历推算，具体合约及临时调整以中金所公告为准。休市日历与行情刷新时段是两个独立功能，日历不会自动修改港美股的行情轮询时段。

## 沪深成交额

在 VS Code 底部状态栏观察**沪深 A 股累计成交额**，交易期间每 **10 秒**获取一次行情。默认与**上一交易日同一时刻**比较，同时显示放量 / 缩量的百分比和金额。

示例（虚构数值）：

```text
成交量 8650.36亿 | 放量 12.35% (+950.73亿)
成交量 7450.80亿 | 缩量 8.21% (-666.40亿)
```

底部“成交量”沿用累计成交额（亿元）统计口径，正常时不显示同刻标记、时间和已收盘等阶段文字。鼠标悬停查看两市各自成交额、行情时间、比较日期、昨日同刻累计额及昨日全天累计额。点击状态栏打开刷新、暂停、比较口径、设置及日志菜单。

## 安装

1. 打开 VS Code 的扩展面板（`Ctrl+Shift+X`）。
2. 点击右上角 `…` → **从 VSIX 安装… / Install from VSIX…**。
3. 选择当前版本的 VSIX（例如 `a-share-turnover-1.19.16.vsix`），安装后按提示重新加载窗口。已安装旧版时直接覆盖升级。
4. 底部右侧出现「成交量」。首次启动会获取行情；休市时也可手动刷新。

## 统计与比较口径

- **成交额**：人民币元，界面换算成**亿元**，不是成交股数或手数。
- **范围**：腾讯行情的 `sh000002`（上证 A 股指数）＋`sz399107`（深证 A 指）对应的累计成交额。覆盖沪深 A 股口径，**不含北交所及 B 股**，不额外叠加创业板或科创板指数，避免重复计算。
- **昨日**：上一交易日。周一对比周五，节假日通过接口的最近交易日分时确定日期。
- **默认同刻比较**：选取沪深两市共同的最新分钟，取当天与上一交易日该分钟的累计成交额；差额 = 当日同刻累计 − 昨日同刻累计，百分比 = 差额 ÷ 昨日同刻累计 × 100%。例如悬浮详情标注 `较昨同刻 10:30`，比较双方都截止 10:30。
- **时间精度**：每 10 秒重新获取实时报价；历史分时精度为**分钟**。顶部成交额来自最新实时报价，同刻缩放量来自两日相同分钟的分时累计值，因此两者可能有数十秒差异。不会把现在的秒级累计值直接除以昨日早一分钟的数据。
- **昨日全天比较**：可在菜单中切换，明确标注 `较昨全天`。悬浮详情默认同时保留这两种比较结果。
- 分时字段的金额已经是累计值，插件不会将其重复累加。两市日期不一致时保留上次完整结果；历史缺失、分钟不匹配、基准为零时明确显示比较待更新，不自动改用全天数据。

## 刷新时间与休市

所有时间固定为**北京时间（Asia/Shanghai）**，不受电脑设置的时区影响。

| 时间 | 行为 |
| --- | --- |
| 工作日 09:30–11:30 | 每 10 秒获取一次 |
| 11:30 | 额外核对一次午盘边界值，之后暂停 |
| 13:00–15:00 | 每 10 秒获取一次 |
| 15:00–15:02 | 每 10 秒核对收盘数据，随后暂停 |
| 盘前、周末、已知节假日 | 自动轮询暂停；启动时或手动操作可获取最近行情 |

内置交易所公布的 **2026 年**节假日。调休补班周末仍休市。未来年份及临时休市可通过 `additionalClosedDates` 补充，或更新插件日历；未覆盖年份默认按周一至周五判断，并在悬浮详情提示。若接口仍返回上个交易日，状态栏会显示警告图标，详情显示日期并注明「非今日行情」。不采集 09:15–09:25 集合竞价阶段。

断网或请求超时会保留上次成功数据，显示「行情未更新」，下个交易时段刷新周期自动重试。缓存保存在 VS Code 全局状态；启动后在新数据到达前明确标记为缓存。请求不重叠，单次 HTTP 请求 8 秒超时；首次获取昨日历史可能跨过一个刷新周期。历史分时成功后只在交易日期变化时重新获取，失败时每分钟重试。

## 设置与命令

在设置中搜索 `牛来盯盘`，或者编辑用户 `settings.json`：

```json
{
  "aShareTurnover.enabled": true,
  "aShareTurnover.comparisonMode": "sameTime",
  "aShareTurnover.showDifferenceAmount": true,
  "aShareTurnover.colorMode": "neutral",
  "aShareTurnover.additionalClosedDates": []
}
```

`comparisonMode` 可改为 `previousDay`。`colorMode` 可改为 `redUpGreenDown`，使用放量红色、缩量绿色。关闭 `showDifferenceAmount` 可缩短状态栏文字。暂停状态在重启 VS Code 后保留，暂停期间仍可手动刷新一次。

命令面板（`Ctrl+Shift+P`）搜索：

- `A股成交额：立即刷新`
- `A股成交额：暂停 / 恢复自动刷新`
- `A股成交额：切换比较口径`
- `A股成交额：打开菜单`
- `A股成交额：查看日志`

网络失败时，先查看「输出 → A股成交额」日志，确认本机可以访问下方行情接口。此版本使用 Node HTTPS 直连，不读取 VS Code 的 `http.proxy`；需要代理的网络请提供系统透明代理或允许该行情域名直连。

## ETF 折溢价与参考净值

点击 ETF 打开内置图表，顶部信息框显示折溢价率、参考净值（IOPV）、同批场内现价和行情时间。正数为溢价，负数为折价；分时和各周期 K 线均可查看。

数据来自腾讯行情；折溢价按同一快照的现价与 IOPV 核对。IOPV 不是正式净值，接口未提供其独立更新时间，跨境 ETF 等品种可能滞后。行情超过 5 分钟标为较早参考，缺失、异常或请求失败时明确提示；不以昨日净值替代 IOPV，也不把最新值当成历史溢价率。
