# 做了一个 VS Code 行情插件：自选股、图表和财经提醒，都放进编辑器

最初只是想在 VS Code 底部看一眼两市成交额，后来把常用的行情查看功能陆续补齐，整理成了这个开源插件：**A股行情**。

不需要一直开着详情页。底部状态栏可以看到成交额和昨日同刻的放量、缩量、领涨板块及最近财经大事；默认显示上证指数，也能切成自己的自选股。想看细节时，再点开图表。

目前支持：

- **自选股**：A 股、港股、美股分组，按名称或代码搜索添加，支持组内拖拽排序和红涨绿跌显示；A 股盘前集合竞价自动刷新。港美股点击在浏览器查看详情。
- **技术图表**：分时、5日分时、日/周/月K、1/5/15/30/60分钟K线，以及均价线、常用均线、MACD/KDJ/RSI；悬停查看历史指标。
- **市场温度**：用涨跌家数、指数走势和成交额变化生成0–100分自定义指标；当天曲线可以查看每个采集时刻的分数，重启保留当天记录。
- **基金**：查看已公布净值涨跌，填写持仓份额和成本后计算个人持仓收益。
- **全球行情**：默认纳指综合、日经225、韩国KOSPI；商品默认伦敦金、布油、伦敦铜、伦敦银，其他自己添加。
- **财经快讯**：底部输出面板阅读7×24资讯，各模块支持独立暂停，图表跟随深浅主题。
- **财经大事**：关注美联储议息、股指交割、A 股/港股/美股休市、美国非农和 CPI；自动更新，标注来源与获取时间，接口失败保留缓存或公告快照。
