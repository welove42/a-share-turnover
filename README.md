## 自选股侧栏

左侧活动栏点击 K 线图标 **STOCK**，打开「自选股」：

1. 点击视图标题上的 **＋**，输入中文名、拼音或编号，例如 `贵州茅台`、`平安`、`gzmt`、`600519`。候选列表显示名称和完整代码，选中回车添加；输入约300毫秒后搜索，快速改词会取消旧搜索，避免串结果。
2. 完整代码可直接添加，支持批量输入 `600519, 000001, 300750, 510300, sz159915`，用空格、中文或英文逗号分隔。网络搜索失败时仍可通过完整代码添加。
3. 每行依次显示 **涨跌幅、现价、名称**，上涨红色箭头、下跌绿色箭头。ETF 保留三位价格小数。
4. 悬停查看代码、昨收、涨跌额、最高 / 最低价和北京时间行情时间。
5. **点击个股行**查看详细图表。右键或行末按钮删除自选、选择在底部显示；顶部提供刷新、排序和暂停 / 恢复。

支持沪深股票、ETF，以及行情源支持的北交所股票。六位代码自动识别市场；也支持 `sh600519`、`sz000001`、`bj920002`、`600519.SH` 等写法。**`000001` 默认指平安银行；上证指数必须写 `sh000001`。** 自选最多 100 个，重复代码自动去重，不预置任何个股。

也可以直接在用户 `settings.json` 中通过代码管理：

```json
{
  "aShareTurnover.stocks.symbols": [
    "sh600519",
    "sz000001",
    "sz300750",
    "sh510300",
    "sz159915"
  ],
  "aShareTurnover.stocks.statusBarSymbol": "sh000001",
  "aShareTurnover.stocks.sortBy": "manual"
}
```

股票代码必须加引号，避免前导零被丢弃。`sortBy` 可选 `manual`、`percentDesc`、`percentAsc`。添加、删除和选择底部代码都会保存到用户设置，重启后保留。若旧版本清单未注册设置、设置文件不可写等原因导致保存失败，会改用插件持久存储，操作仍然生效；下次成功写入设置后恢复正常。设置页面手动编辑名单时应填写股票代码，名称搜索通过添加入口进行。

## 全球指数

STOCK 中自选股列表下方的 **全球指数** 折叠栏目默认只显示三项，按以下顺序直接列出：**纳斯达克综合（NDX）、日经225（N225）、韩国KOSPI（KS11）**。

- 点击栏目右上角 **＋**，按中文名、英文代码、别名或地区搜索其他指数，例如 `标普`、`SPX`、`恒生`、`美国`；可勾选多个后回车添加。已添加的指数有标注，重复选择不会重复添加。
- 点击行末 **垃圾桶** 或右键 **删除指数** 移除；新增项按添加顺序放在列表末尾。删除默认项或删空列表也会保留，不会在刷新或重启后恢复。
- 可添加的完整目录来自东方财富，仅在添加时加载并缓存，接口暂不可用时使用本地候选，目录失败不影响当前行情；目录及旧版行情缓存不决定显示列表。从1.4.0升级后默认回到上述三项，额外指数需自行添加。纳斯达克综合 `NDX` 与纳斯达克100 `NDX100` 分别提供。
- 每行显示 **涨跌幅、指数点位、名称、行情时间**，红涨绿跌；悬停查看涨跌点数、昨收、今开、最高、最低及北京时间。点击指数在浏览器打开对应详情。
- 栏目可见且列表非空时每 **10秒**刷新，不受A股开闭市影响；隐藏后停止持续请求，再次展开时刷新。支持独立手动刷新和暂停，暂停状态会保存。
- 第三方行情可能延迟，以所示报价时间为准；获取失败保留旧数据并标注，重启缓存显示“缓存”。

也可以直接编辑用户设置；支持完整ID或不带前缀的英文代码，空数组表示不显示任何指数：

```json
{
  "aShareTurnover.globalIndices.symbols": ["100.NDX", "100.N225", "100.KS11"]
}
```

`aShareTurnover.globalIndices.enabled` 可单独关闭栏目，不影响A股自选、成交额和新闻。数据源：[东方财富全球指数行情](https://quote.eastmoney.com/center/gridlist.html#global_qtzs)，纳斯达克综合、日经225、韩国KOSPI、道琼斯和标普500使用[新浪财经](https://finance.sina.com.cn/stock/usstock/)作为独立备用源。

每次只请求已选代码。主批量接口断开后冷却5分钟，期间优先使用备用报价；缺失项采用独立逐项请求补查，失败的逐项接口冷却60秒。全部报价源失败时按20、40、60秒延长自动重试间隔，有成功报价后恢复10秒。手动刷新可立即重试，但仍遵守失败接口的冷却，避免连续点击触发请求风暴。

行内“备用”及悬浮提示标明实际来源。东方财富保留其行情时间；新浪使用带日期的来源更新时间，不将无日期的旧版指数行情或股指期货替代现金指数。不同源的更新时间不等同于逐笔成交时间，价格也可能存在延迟；同源倒退或异常未来时间不会覆盖已保存报价。

## 基金与个人持仓收益

STOCK 下新增独立的 **基金** 折叠栏目，默认空列表，最多关注50只基金。

1. 点击栏目右上角 **＋**，输入中文名称、拼音或六位基金代码（保留前导零），选择候选后添加。完整代码也可批量输入，例如 `110020, 000198`；这里的代码仅为操作示例。
2. 普通净值型基金显示 **已公布净值日涨跌、单位净值、基金名称、净值日期**。列表可见时每60秒检查更新，隐藏后停止持续请求；支持手动刷新和独立暂停。日涨跌采用数据源公布值，缺失时显示“—”，不根据未复权净值自行推算。
3. 点击行末 **铅笔**，依次填写 **当前已确认持仓份额**、**剩余持仓总成本**。两步都完成才保存，取消不会修改之前的持仓。金额应与基金净值同币种，总成本可包含费用，不是单位成本。
4. 设置后列表显示持仓收益和收益率；悬停可查看份额、总成本、市值、计算日期和公式：`市值 = 份额 × 单位净值`，`持仓收益 = 市值 − 总成本`，`收益率 = 持仓收益 ÷ 总成本 × 100%`。
5. 申购、赎回、份额折算或分红再投资后需手动更新份额和剩余成本；已收现金分红可自行从成本扣除。此处是当前剩余持仓按公布净值计算的盈亏，不自动处理交易流水、汇率换算或已赎回收益。
6. 货币基金单独显示 **万份/百份收益、七日年化及日期**，不把收益字段当净值。货币基金累计持仓收益依赖交易流水，本版不按单位净值估算其个人持仓盈亏。

持仓份额、成本只保存于本机扩展存储，不写入用户/项目设置，也不会发送给行情接口。关注代码保存在 `aShareTurnover.funds.symbols`；设置 `aShareTurnover.funds.enabled` 可单独关闭栏目。右键 **移出列表** 保留本机持仓，重新添加会恢复；**清除本机持仓** 则保留基金关注，仅清除份额和成本。

基金数据由[天天基金 / 东方财富](https://fund.eastmoney.com/)提供，使用已公布净值，不提供盘中估算。QDII等基金可能晚于A股日期更新，始终显示真实公布日期；断网保留旧数据并标注获取失败，重启缓存标注“缓存”。点击基金行在浏览器查看完整基金详情。

## 底部上证指数与个股切换

底部新增一项，默认显示 **`[上证指数] 3697.52 ▲ (+0.19%)`**（示例）。**点击这一项**会弹出选择列表，可以选择上证指数或已经加入自选的任何个股 / ETF；选中后立即切换，行情与侧栏共用一次批量请求。

删除正在底部显示的自选股后，自动恢复上证指数。原来的沪深成交额状态栏同时保留，点击成交额项仍打开原有菜单。

自选股和底部指数在北京时间交易日 **09:15–11:30、13:00–15:00** 每 **10 秒**请求一次。09:15–09:25显示“集合竞价”，09:25–09:30显示“待开盘”并继续刷新，09:30自动衔接正常行情。集合竞价时段依据[上交所交易时间说明](https://one.sse.com.cn/onething/gptz/)。

09:15前、午休和已知休市停止持续轮询，收盘后短暂核对最终报价；启动及阶段切换时会核对一次。可随时手动刷新，暂停或禁用后不会自动请求。报价以行情源返回为准，可能在等待开盘期间保持不变。若接口失败，保留上次报价并标注「未更新」或缓存日期。停牌 / 尚无成交时显示「—」，不会把零报价算成跌 100%。

`aShareTurnover.stocks.enabled` 控制自选股及底部指数显示，独立于成交额的 `aShareTurnover.enabled`。可通过命令 `A股自选股：添加股票代码`、`选择底部显示的指数或个股` 等操作。

## 点击个股查看详细图表

点击 STOCK 中任一个股 / ETF 行，在编辑区打开行情详情标签。**所有股票共用一个详情标签**：点击其他股票时更新标题和内容，并保留当前图表类型；重复点击同一股票只聚焦，不重载网页。命令面板的 `A股自选股：查看详细行情图表` 默认打开底部当前显示的代码，因此也能查看上证指数。

**分钟K线**：支持1、5、15、30、60分钟，使用腾讯行情的真实开高低收和成交量，显示最近60 / 120 / 180根，指标以获取的最多240根数据计算。时间为周期结束时间，最后一根可能尚未完成；源数据不复权，部分品种可能无数据。

**风险提示**：默认在上证指数跌幅至少1.5%且沪深成交额较昨日同刻放量或缩量至少30%时，在成交量状态栏显示“放量下跌”或“缩量下跌”。悬停可查看数值与阈值；行情过期、暂停、失败、不同日期或时间相差超过2分钟时不提示。可用 `aShareTurnover.risk.enabled`、`risk.volumePercent` 和 `risk.dropPercent` 设置。此提示使用上证指数，不随底部选中个股改变。

**周期直接在图表内切换**：股票名称下方有紧凑的“分时 / 日K / 周K / 月K”按钮，当前周期高亮。点击立即切换并保留当前指标，重复点击当前周期不会重载；切换其他股票后仍保留所选周期。

编辑器右上角仍提供四个图标按钮：**切换图表类型**（折线图图标，选择分时 / 日K / 周K / 月K及网页模式）、**切换技术指标**（脉冲图标）、**刷新当前图表**、**在浏览器打开当前图表**。按钮仅在行情详情标签出现；切换菜单会标出当前类型，并提供用途说明。

- **分时图（内置，默认）**：使用腾讯行情直接绘制最近交易日的分钟价格、昨收参考线、涨跌幅及每分钟成交量，午休时间轴合并，不加载东方财富网页。股票和ETF的黄色均价线 = 累计成交额（元）÷累计成交量（手）÷100，包含当日集合竞价成交；它是成交量加权均价，不是价格的简单平均。指数的成分股成交量无法用于计算指数均价，因此指数不画此线。源数据缺失、无成交或成交额异常时显示“—”，不估算。
- **日K图（内置）**：开高低收蜡烛图、MA5 / MA10 / MA20 / MA30 / MA60 和每日成交量，可切换60 / 120 / 180根显示范围。腾讯返回前复权数据时明确标注“前复权”，指数等无复权数据时标注“不复权”。行情源可能只提供少量历史，按实际可用记录显示。
- **周K / 月K图（内置）**：读取行情源原生周线和月线，显示周期内开高低收、成交量和 MA5 / MA10 / MA20 / MA30 / MA60；支持60 / 120 / 180根。当前周/月最后一根尚未收完，会随行情更新，显示实际数据截止日期。
- **常规图表（东方财富）**：按需以 iframe 嵌入 `/basic/full.html` 专用图表页，支持分时、日K及其他周期。沪市使用市场参数1，深市和北交所使用0。网页自行更新行情，插件不会每10秒重载网页。
- **筹码盘口（东方财富）**：沪深A股个股可切换到 `/basic/h5chart-iframe.html`，查看盘口、买卖五档及K线。选择网页内部的 **日K → 筹码分布** 显示筹码图。指数、ETF和北交所暂不开放该入口；从筹码模式切换到这些品种时自动使用内置分时。
- 鼠标移动或聚焦图表后按左右方向键，查看对应分钟 / 日期的开高低收、涨跌额、涨跌幅、振幅、成交量及均线。主图MA5/10/20/30/60和副图图例同步对应位置；成交量区增加VMA5/10。悬浮卡同时列出该时刻MACD（DIF、DEA、柱）、KDJ（K、D、J）、RSI6/12/24，未满窗口显示“—”。分时另显示均价、分钟与累计成交额、成交量。K线接口未提供历史成交额，不使用价格乘成交量估算。图表价格由对应接口精度决定，ETF日K可能比实时报价少一位小数。
- 图表标签可见且交易期间，插件内图表每10秒更新数据；隐藏、关闭或午休后停止轮询。失败保留上次图表并提示；重新显示或手动刷新可获取最新数据。

设置 `aShareTurnover.charts.defaultMode` 可选择新详情标签的默认类型：`intraday`（默认内置分时）、`daily`（内置日K）、`weekly`（内置周K）、`monthly`（内置月K）、`eastmoney`（网页常规）或 `chips`（网页筹码）。已有标签切换个股时保留当前类型。

**技术指标**：默认显示 **MACD (12,26,9)** 副图；右上角“切换技术指标”可选择 **KDJ (9,3,3)**、**RSI (6,12,24)** 或隐藏。指标选择保存在本机，切股、切换周期和重启后保留；切换指标只在本地计算，不请求行情接口。鼠标或左右方向键定位时，悬浮卡、主副图图例和下方详情同步显示所选时间的指标数值。10秒刷新及切换副图保留已选时间，移出图表、失去焦点或按Esc恢复最新；切换周期或分时跨交易日时清除旧定位。

- MACD：DIF = EMA12 − EMA26，DEA = DIF的EMA9，红绿柱 = 2 × (DIF − DEA)；EMA以首个可用价格初始化。公式参考[富途MACD说明](https://support.futunn.com/hant/topic165)与[中国证券投资基金业协会投教资料](https://investor.amac.org.cn/community/tzzhdzthd/ylj/202304/P020230410490474818370.pdf)。
- KDJ：9周期最高/最低价计算RSV，K和D分别按1/3权重平滑，J = 3K − 2D；本插件以50初始化，窗口未满9根不输出，等价区间RSV取50，J可超出0–100。公式参考[富途KDJ说明](https://support.futunn.com/topic149)。
- RSI：6、12、24周期，先用前N个涨跌价差均值初始化，再用Wilder平滑；无涨跌时取50，窗口不足显示“—”。算法参考[TradingView RSI说明](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/)。

K线请求240根历史，先用全部已获取记录计算，再截取60/120/180根显示范围，切换范围不会重新初始化指标。MA和VMA周期均按当前K线根数计算（周K的MA5为5周、5分钟K的MA5为5根5分钟K）；涨跌额、涨跌幅及振幅按同一复权口径的前一根K线收盘价计算，缺前值或前值不为正时显示“—”。不同历史长度、复权口径和起始值可能造成与其他软件的数值差异。长期前复权历史可能出现负价格，按源数据保留。

分时的指标基于**当日分钟采样价格**并每日重置；KDJ使用采样价格区间，不代表完整1分钟K线高低价。日K、周K、月K则分别以对应周期的真实开高低收计算。

**验证码与请求优化**：网页验证由东方财富控制，仍可能出现在常规或筹码页面。使用右上角“切换图表类型”转到内置图表即可继续看分时或日K；需要完整筹码功能时，可用“在浏览器打开当前图表”并手动完成验证。浏览器与插件的登录、验证状态彼此独立，完成浏览器验证不保证 iframe 同步通过。插件不会自动识别、完成验证码或复制网站登录凭证。

网页只在宿主确认当前模式后才加载，400毫秒内快速切换类型只加载最终选择；重复选择同一网页不重载，连续网页刷新间隔至少5秒。内置图表按股票和类型复用10秒内的数据，手动刷新间隔至少2秒；切到内置模式会卸载第三方网页。

切换个股会取消旧行情请求，并让旧页面消息失效，避免串股。编辑器右上角的 **在浏览器打开当前图表** 在网页模式下打开当前专用图表，插件内图表模式及个股右键菜单则打开完整行情页。

**自动主题适配**：VS Code 使用暗色主题时，常规图表和筹码盘口采用夜间显示；浅色主题使用原站配色。深色高对比度主题使用黑底效果，浅色高对比度主题保留浅色。第三方网页通过显示层调整配色，红涨绿跌仍可辨认；插件内图表继续使用主题变量。切换主题即时生效，无需刷新，保留当前股票、图表周期及筹码显示状态。

专用页面和单标签交互参考 [leekfund](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/src/webview/stockTrend.ts)。第三方网页的访问策略、数据和登录状态由网站自身管理；内置图表数据通过腾讯行情接口读取。

## 原成交额功能

底部“成交量”沿用累计成交额（亿元）统计口径，正常时不显示同刻标记、时间和已收盘等阶段文字。鼠标悬停查看两市各自成交额、行情时间、比较日期、昨日同刻累计额及昨日全天累计额。点击状态栏打开刷新、暂停、比较口径、设置及日志菜单。

## 统计与比较口径

- **成交额**：人民币元，界面换算成**亿元**，不是成交股数或手数。
- **范围**：腾讯行情的 `sh000002`（上证 A 股指数）＋`sz399107`（深证 A 指）对应的累计成交额。覆盖沪深 A 股口径，**不含北交所及 B 股**，不额外叠加创业板或科创板指数，避免重复计算。
- **昨日**：上一交易日。周一对比周五，节假日通过接口的最近交易日分时确定日期。
- **默认同刻比较**：选取沪深两市共同的最新分钟，取当天与上一交易日该分钟的累计成交额；差额 = 当日同刻累计 − 昨日同刻累计，百分比 = 差额 ÷ 昨日同刻累计 × 100%。例如悬浮详情标注 `较昨同刻 10:30`，比较双方都截止 10:30。
- **时间精度**：每 10 秒重新获取实时报价；历史分时精度为**分钟**。顶部成交额来自最新实时报价，同刻缩放量来自两日相同分钟的分时累计值，因此两者可能有数十秒差异。不会把现在的秒级累计值直接除以昨日早一分钟的数据。
- **昨日全天比较**：可在菜单中切换，明确标注 `较昨全天`。悬浮详情默认同时保留这两种比较结果。
- 分时字段的金额已经是累计值，插件不会将其重复累加。两市日期不一致时保留上次完整结果；历史缺失、分钟不匹配、基准为零时明确显示比较待更新，不自动改用全天数据。

## 刷新时间与休市

所有时间固定为**北京时间（Asia/Shanghai）**，不受电脑设置的时区影响。

| 时间 | 行为 |
| --- | --- |
| 工作日 09:30–11:30 | 每 10 秒获取一次 |
| 11:30 | 额外核对一次午盘边界值，之后暂停 |
| 13:00–15:00 | 每 10 秒获取一次 |
| 15:00–15:02 | 每 10 秒核对收盘数据，随后暂停 |
| 盘前、周末、已知节假日 | 自动轮询暂停；启动时或手动操作可获取最近行情 |

内置交易所公布的 **2026 年**节假日。调休补班周末仍休市。未来年份及临时休市可通过 `additionalClosedDates` 补充，或更新插件日历；未覆盖年份默认按周一至周五判断，并在悬浮详情提示。若接口仍返回上个交易日，状态栏会显示警告图标，详情显示日期并注明「非今日行情」。不采集 09:15–09:25 集合竞价阶段。

断网或请求超时会保留上次成功数据，显示「行情未更新」，下个交易时段刷新周期自动重试。缓存保存在 VS Code 全局状态；启动后在新数据到达前明确标记为缓存。请求不重叠，单次 HTTP 请求 8 秒超时；首次获取昨日历史可能跨过一个刷新周期。历史分时成功后只在交易日期变化时重新获取，失败时每分钟重试。

## 设置与命令

在设置中搜索 `A股成交额`，或者编辑用户 `settings.json`：

```json
{
  "aShareTurnover.enabled": true,
  "aShareTurnover.comparisonMode": "sameTime",
  "aShareTurnover.showDifferenceAmount": true,
  "aShareTurnover.colorMode": "neutral",
  "aShareTurnover.additionalClosedDates": []
}
```

`comparisonMode` 可改为 `previousDay`。`colorMode` 可改为 `redUpGreenDown`，使用放量红色、缩量绿色。关闭 `showDifferenceAmount` 可缩短状态栏文字。暂停状态在重启 VS Code 后保留，暂停期间仍可手动刷新一次。

命令面板（`Ctrl+Shift+P`）搜索：

- `A股成交额：立即刷新`
- `A股成交额：暂停 / 恢复自动刷新`
- `A股成交额：切换比较口径`
- `A股成交额：打开菜单`
- `A股成交额：查看日志`

网络失败时，先查看「输出 → A股成交额」日志，确认本机可以访问下方行情接口。此版本使用 Node HTTPS 直连，不读取 VS Code 的 `http.proxy`；需要代理的网络请提供系统透明代理或允许该行情域名直连。

## 源码运行与打包

直接使用 VS Code 打开本目录并按 **F5**，会在扩展开发宿主中启动插件，无需编译。

```sh
npm ci
npm test
npm run smoke
npm run smoke:stocks
npm run smoke:news
npm run smoke:charts
npm run package
```

`npm test` 为离线测试，覆盖交易时段、金额单位、同刻对齐、跨日、缓存、断网、暂停及请求重叠等情况。`npm run smoke` 会访问真实行情，打印当前结果并验证两种比较数据完整性。打包使用 VS Code 官方 `@vscode/vsce`；本地安装不需要发布凭证；本仓库 Publisher ID 为 `welove42`，发布到市场需要该发布者的权限，可通过管理页上传 VSIX，或在本机完成 `vsce login welove42` 后运行 `vsce publish --no-dependencies`。不要把 PAT 放入源码或 Git 仓库。
